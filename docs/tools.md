# Writing a tool

How to add a deterministic tool so the model can use it without prompt changes: the manifest
(purpose, when to use, cost, evidence kind, bounds, model schema and input schema), the result
envelope, built-in versus MCP transport, and the `visual_only` projection. Filled in task 4.1 with
the `view` manifest as the worked example; the contract is in `SPEC.md` under "Tools".
